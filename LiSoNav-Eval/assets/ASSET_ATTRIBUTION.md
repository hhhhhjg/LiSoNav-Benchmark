# Movable-object asset attribution

LiSoNav-Eval uses YCB- and HSSD-derived objects. `source_dataset_map.json`
records the source family for each object.

## YCB-derived objects

- Source: Yale-CMU-Berkeley Object and Model Set
- Project: <https://www.ycbbenchmarks.com/>
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: <https://creativecommons.org/licenses/by/4.0/legalcode>
- Modifications: Habitat-Sim-compatible meshes, collision meshes, object
  configurations, descriptions, and reference renders.

## HSSD-derived objects

- Source: Habitat Synthetic Scenes Dataset (HSSD)
- Project: <https://3dlg-hcvc.github.io/hssd/>
- Distribution page: <https://huggingface.co/datasets/hssd/hssd-hab>

- License text: <https://creativecommons.org/licenses/by-nc/4.0/legalcode>

  configurations, descriptions, and reference renders.
